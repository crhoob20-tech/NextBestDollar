## Overview

NextBestDollar is an independent financial technology project designed to help individuals make informed decisions about how to allocate their money.

The application focuses on comparing financial priorities, including debt repayment, savings, retirement contributions, and investments.

The goal is to make financial decision-making more accessible through financial modeling, forecasting, and interactive analysis.

## Core Features

- **Financial Decision Analysis:** Compare competing financial priorities and evaluate financial trade-offs.
- **Scenario Modeling:** Explore how different financial assumptions affect outcomes.
- **Financial Forecasting:** Assess potential long-term financial implications.
- **Interactive Interface:** Explore financial decisions through a browser-based application.
