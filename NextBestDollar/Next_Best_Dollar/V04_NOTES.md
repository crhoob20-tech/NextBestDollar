# Refined v0.4

Whole date control opens a compact month calendar. Arrow navigation, selected-day highlight, year/month selection, Escape and optional-date clearing remain available. Birthday dates in the future cannot be selected.

Wheel gestures over inputs route to the surrounding scrollable page and stop native value-changing behavior. Questionnaires no longer require dragging the scrollbar.

Goal cards and shared profile panels use rounded surfaces. Profile category charts are doughnuts; Plan retains contribution-versus-growth curves. Projection return prompts now offer dated source-backed references and separate examples, with source links. Account wrappers are not assigned stock returns automatically. The S&P reference is for the index, not individual stocks. Cash uses a dated savings benchmark, not a current APY quote.

14 automated tests pass and Python modules compile. Native visual verification remains outstanding; screenshots attached to the request were unavailable. Existing local database has not been changed and is excluded from the archive.
